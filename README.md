# Villain-s-Tale
Videojuego desarrollado como proyecto intermodular de Daniel, Eloy y Abel.

El directorio VillainsTale es el proyecto ya compilado, listo para ejecutar y probar.
Src contiene los archivos y directorios que usa RPGMaker a la hora de poder editar y modificar el juego. Lo que usamos nosotros para trabajar.
Docs contiene la documentación del proyecto y prototipos tempranos que usamos al principio de empezar.
